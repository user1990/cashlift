CashLift is the cash decision command center for service firms. It makes the cash impact of approvals, receivables, vendor spend, budgets, and runway visible in one operating view.

## Start here

- [Getting started](/getting-started) — run the public demo or configure a production workspace.
- [Product guide](/product) — understand the cash workflows CashLift brings together.
- [Architecture](/architecture) — learn the route, module, and data boundaries.
- [Engineering guides](/engineering) — work with validated data, images, and quality checks.
- [Operations](/operations) — understand CI and the docs build/deployment boundary.

## Documentation principles

- Product behavior is described from the current routes and modules, not aspirational roadmap items.
- Engineering guidance explains the rules that protect correctness and maintainability.
- Architecture documents the stable route, module, data, and tooling boundaries.

Run `pnpm docs:dev` to work on this site locally.
