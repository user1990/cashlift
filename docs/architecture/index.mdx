CashLift separates public marketing, public demo, and authenticated workspace concerns.

```text
Marketing routes → public product information
Public demo routes → static read-only fixture tour
Dashboard routes → Clerk-authenticated company workspace
                         ↓
                 Server repository → Supabase RLS
```

## Source ownership

<FileTree>

- 📁 **src/**
  - 📁 **app/**
    - Route wrappers, layouts, metadata, auth gates, and composition.
  - 📁 **modules/**
    - Product capabilities and workspace data.
  - 📁 **ui/**
    - Generic reusable UI primitives.
  - 📁 **services/**
    - Clerk, Supabase, Sentry, environment configuration, and i18n.
  - 📁 **utilities/**
    - Domain-agnostic helpers.
- 📁 **supabase/**
  - Schema and row-level security policies.
- 📁 **e2e/**
  - Playwright end-to-end tests.
- 📁 **.storybook/**
  - Storybook configuration.
- 📁 **docs/**
  - Blume documentation source.

</FileTree>

Business modules should not casually import other business modules. Routes compose them, while explicit composition modules such as `dashboard`, `workspace`, and `page-shell` own their documented cross-module relationships.

## Data boundary

Workspace pages resolve data on the server. In demo mode, the resolver returns the typed Studio Nova fixture. In production, it requires Clerk and Supabase configuration, authenticates the user, and uses company-scoped row-level security. Browser code does not query finance tables directly.

## Route groups

- `(marketing)` contains public marketing, use-case, legal, and demo-entry routes.
- `(public-demo)` contains the public read-only workspace tour.
- `(workspace)` contains authenticated dashboard routes for overview, approvals, budgets, cash, invoices, vendors, team, and settings.
- `(auth)` contains sign-in and sign-up routes.

## Storybook

Storybook is the component workbench for reusable UI states and generated component documentation.

- [Open the deployed Storybook](https://cashlift-storybook.vercel.app/)
- Run `pnpm storybook` for local development on port 6006.
- Run `pnpm build-storybook` to produce the static site.
