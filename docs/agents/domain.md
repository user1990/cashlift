# Domain Docs

CashLift is a single-context repository.

## Before exploring

- Read `CONTEXT.md` at the repository root.
- Read ADRs under `docs/adr/` that touch the area being changed.
- If either source is absent, continue without creating replacement documentation speculatively.

## Vocabulary

Use the glossary terms from `CONTEXT.md` in issue titles, implementation plans, tests, and product copy. Avoid synonyms that the glossary explicitly rejects.

## ADR conflicts

Surface any conflict with an accepted ADR explicitly. Update or supersede the ADR before implementing behavior that contradicts it.
