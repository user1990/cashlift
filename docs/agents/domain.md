# Domain Docs

CashLift uses a single-context domain documentation layout.

## Before exploring

- Read `CONTEXT.md` at the repository root.
- Read relevant decision records under `docs/decisions/` that touch the area being changed.
- If either source is absent, proceed without proposing documentation solely to fill the gap.

## Vocabulary

Use the terms defined in `CONTEXT.md` in issue titles, implementation plans, tests, and review findings. Avoid synonyms the glossary rejects. If a needed concept is missing, flag the gap instead of silently inventing a new term.

## Architectural decisions

Surface conflicts with an existing ADR explicitly. Do not silently override an accepted decision.
