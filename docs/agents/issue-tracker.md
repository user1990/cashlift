# Issue Tracker

CashLift issues live in the **CashLift** team in Linear.

## Workflow

- Use the connected Linear app to read and publish issues.
- Create issues directly in the CashLift team; no project is required unless a task specifies one.
- Apply the `ready-for-agent` label to fully specified implementation tickets.
- Publish blocking relationships with Linear's native `blockedBy` and `blocks` relations.
- Do not treat external pull requests as incoming triage requests.

## Ticket content

Each implementation ticket should describe one demoable vertical slice, list acceptance criteria, and declare every blocking issue. Use CashLift domain language from `CONTEXT.md`.
