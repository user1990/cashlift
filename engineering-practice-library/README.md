## Deploy to ChatGPT Sites

This tree is the static source for
https://engineering-practice-library.paulius-rimg1990.chatgpt.site/course/

Cursor cannot publish to `chatgpt.site`. In ChatGPT desktop, open the existing Site (or `@Sites` on this folder) and ask:

```
Save a version of this static library, then deploy it to the existing
engineering-practice-library Site. Keep it a content-led site with no new
database. Confirm the live URL after deploy.
```

Do not create a second Site. Review the version, then deploy so the current public URL updates.
