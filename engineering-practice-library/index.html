Recommended route

A practical way through

Spaced retrieval
01

Build the base

Complete the seven Teach lessons first. Practice prompt → check → human decision, then story → evidence → quality gate.

02

Own the bottleneck

Map idea → users, circle the slow step, and practice shipping, hats, and maintenance. Do not start here if you cannot yet place a rule in prompt, check, or human.

03

Broaden your AI workflow

Use 40 AI Truths one lesson at a time: apply each drill to a real repo, workflow, PR, product idea, or automation.

04

Rehearse React decisions

Start with the mid-level React lesson. Answer aloud using context → choice → trade-off → proof before opening the explanation.

05

Calibrate seniority

Move through Staff Interview Prep, then the Senior / Staff course. Bring real project evidence into every exercise and mock loop.

06

Run the principal sprint

Use the seven-day Principal Frontend Preparation sprint, progressing from intermediate to advanced to expert topics.

07

Direct the system

Before a risky agent task, write the architecture delta: boundaries, data flow, failure paths, checks, and the human decision still required.

Study method

Learn by retrieval, then transfer.

  1. Read one lesson.
  2. Answer before revealing feedback.
  3. Apply the drill to a real artifact.
  4. Return later and explain it without reading.
