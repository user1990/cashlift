More context is not always better

Staff-level point: Context rot kills the signal. Staff-level work is deciding what context belongs in the window and what belongs in durable state.

Real Product / Engineering Example

Build a code-review agent that receives only the diff, test output, ownership rules, and risk checklist instead of the entire repository history.

Practice Drill

Practice context budgeting for an auto-review workflow: list required, optional, and forbidden context. Then write a 12-line reviewer prompt.

Operating Checklist

  • Define the business or engineering outcome before touching tools.
  • Name the owner, inputs, output, verification, and failure path.
  • Use examples or fixtures when quality matters.
  • Make the model show uncertainty or route to a human when needed.
  • Record the reusable prompt, context pack, or runbook.

Feedback Loop

Pass condition: Prompt contains goal, constraints, exact inputs, output format, and no irrelevant history.
