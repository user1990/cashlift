First draft is a rough cut, not final

Staff-level point: Round one is material. Quality comes from critique loops and human taste.

Real Product / Engineering Example

AI drafts a migration plan; a second pass audits rollback, data safety, observability, and test gaps; you approve final.

Practice Drill

Run generate -> critique -> revise on one real artifact: PRD, test plan, architecture note, code review.

Operating Checklist

  • Define the business or engineering outcome before touching tools.
  • Name the owner, inputs, output, verification, and failure path.
  • Use examples or fixtures when quality matters.
  • Make the model show uncertainty or route to a human when needed.
  • Record the reusable prompt, context pack, or runbook.

Feedback Loop
