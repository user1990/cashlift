A prompt you cannot repeat is luck

Staff-level point: Prompts need versioning, fixtures, and expected outputs.

Real Product / Engineering Example

Create versioned prompts for PR review with sample diffs and expected comments.

Practice Drill

Save one successful prompt as a template with variables, example input, expected output, owner, and version.

Operating Checklist

  • Define the business or engineering outcome before touching tools.
  • Name the owner, inputs, output, verification, and failure path.
  • Use examples or fixtures when quality matters.
  • Make the model show uncertainty or route to a human when needed.
  • Record the reusable prompt, context pack, or runbook.
