Lesson 4 of 40

Lazy input creates lazy output

Staff-level point: Low-quality prompting is low-quality engineering. The work starts before the model call.

Real Product / Engineering Example

Before asking AI to implement a feature, gather ticket, current files, failing test, product goal, constraints, and non-goals.

Practice Drill

Create a pre-flight checklist for “AI implements software task” and use it on a real task.

Operating Checklist

  • Define the business or engineering outcome before touching tools.
  • Name the owner, inputs, output, verification, and failure path.
  • Use examples or fixtures when quality matters.
  • Make the model show uncertainty or route to a human when needed.
  • Record the reusable prompt, context pack, or runbook.

Feedback Loop

Pass condition: Checklist prevents missing files, test commands, and product constraints.
