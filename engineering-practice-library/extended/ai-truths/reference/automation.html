Automation Readiness Reference

Automate stable, repeated, measurable work.

Use This Checklist

  • Manual process exists.
  • Inputs are reliable.
  • Owner is assigned.
  • Metric is defined.
  • Failure path is known.
  • Maintenance cost is lower than saved effort.
