Agent Workflow Reference

Prefer simple workflows before autonomous agents.

Use This Checklist

  • Trigger: what starts the workflow?
  • State: what must persist?
  • Tools: what can it call?
  • Control flow: deterministic code or model choice?
  • Approval: when does a human decide?
  • Observability: how do we know it worked?
