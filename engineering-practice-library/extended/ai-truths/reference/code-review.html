AI Code Review Reference

AI review is useful only when it improves code health.

Use This Checklist

  • Keep PRs small enough for meaningful review.
  • Ask for bug risk, security risk, test gaps, maintainability, and product behavior.
  • Use repo instructions and examples.
  • Treat AI comments as suggestions requiring engineer judgment.
  • Measure false positives and missed defects.
