Context Engineering Reference

Context is a scarce resource. Staff engineers curate it.

Use This Checklist

  • Required context: changes the answer.
  • Optional context: useful but not essential.
  • Forbidden context: distracts or leaks sensitive data.
  • Durable context: belongs in files, docs, memory, or retrieval.
  • Ephemeral context: belongs in the current task only.
