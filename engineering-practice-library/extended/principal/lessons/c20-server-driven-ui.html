Server-driven UI: dynamic layouts

Server-driven UI trades local flexibility for centralized orchestration and cross-platform consistency.

Sprint index

The rule

Use it when layout/content must change without redeploying clients, but protect type safety, observability, and fallback behavior.

Example

A JSON-defined promotion module can be controlled centrally, but payment and compliance UI need stricter contracts.

Practice

Pick one screen and mark which parts could be server-defined and which must remain locally coded.
