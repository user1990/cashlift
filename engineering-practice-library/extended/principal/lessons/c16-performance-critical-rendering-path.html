Performance: critical rendering path

Critical rendering path work is about getting the first useful pixels and first useful interaction earlier.

Sprint index

The rule

Prioritize critical HTML/CSS, defer non-critical JS, reduce render-blocking resources, and measure paint/layout/compositing costs.

Example

A trust summary should not wait for a charting library, third-party widget, and all below-the-fold data.

Practice

Draw the critical path for one page: HTML, CSS, fonts, JS, data, image, first paint, first interaction.

Write a concrete answer, then check.

Good answer direction

Strong answer: I optimize the path to the first useful user decision, then guard it with metrics.
