Lesson 0004

Rendering strategy: route-level tradeoffs

Do not pick SSR, SSG, ISR, or client rendering globally. Pick per route and per interaction.

Sprint index

The decision frame

Choose rendering by asking five questions: does it need SEO, personalization, fresh data, instant trust signal, or heavy interaction? The answer often changes inside the same product.

Primary sources: Next.js App Router, Next.js Server and Client Components.

Example

A vehicle report is authenticated and trust-critical. The report shell can be server-rendered with auth and cache rules. Expandable sections, filters, and charts can be client components. Marketing pages can be static or incrementally regenerated.

Good answer direction

"I would not use one rendering strategy for the whole product. Marketing pages optimize for SEO and cache. Authenticated reports optimize for data correctness, fast meaningful content, and clear loading/error boundaries."
