WASM: near-native modules in the browser

WASM is a deployment target for performance-sensitive or polyglot code, not a replacement for JavaScript UI.

Sprint index

The rule

Use WASM when compute-heavy code, existing native libraries, or predictable performance justify boundary complexity.

Example

Image processing or VIN decoding rules might justify WASM; rendering normal forms does not.

Practice

Pick one expensive operation and decide whether JS, Web Worker, or WASM is the right move.

Write a concrete answer, then check.
