Offline-first: service workers, PWA, IndexedDB

Offline-first design means deciding what should still work when the network does not.

Sprint index

The rule

Cache shell and stable assets carefully; store user data intentionally; design sync, conflict, and retry behavior.

Example

A saved vehicle comparison could work offline, while purchasing a fresh report must clearly require network freshness.

Practice

Choose one feature and mark which data can be cached, edited offline, synced later, or must be online-only.

Write a concrete answer, then check.

Good answer direction

Strong answer: I separate offline viewing from offline mutation and make sync/conflict states visible.
