Local-first systems: optimistic replication

Local-first systems make the local copy useful first, then reconcile with the network.

Sprint index

The rule

Design for offline parity, conflict handling, durable local state, sync visibility, and optimistic rollback.

Example

A draft inspection checklist can be edited offline, synced later, and marked when conflicts need review.

Practice

For one editable feature, write local store, sync trigger, conflict policy, and user-visible status.
