C07

Fonts: loading without layout shift

Font choices affect both brand feel and layout stability.

Sprint index

The rule

Use sensible fallbacks, font-display intentionally, preloading selectively, and metrics-compatible fallback stacks when possible.

Example

A custom heading font can be fine; body text needs a fallback that does not shift the entire page when the font loads.

Practice

Inspect one page with custom fonts. Note font files, display strategy, fallback stack, and visible shift risk.

Write a concrete answer, then check.

Good answer direction

Strong answer: I treat fonts as performance assets and design fallback behavior, not just typography.
