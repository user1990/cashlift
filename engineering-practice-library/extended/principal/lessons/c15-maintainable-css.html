Maintainable CSS: architecture tradeoffs

CSS architecture is about change control: who can safely modify what without unexpected visual regressions.

Sprint index

The rule

Choose utility, component, CSS-in-JS, BEM, or atomic approaches based on team workflow, scale, runtime cost, and design system needs.

Example

A design system primitive needs stable tokens and variants; a one-off marketing page may benefit from local composition.

Practice

For one component, write which styles are tokens, variants, layout, state, and one-off exceptions.
