Deployment basics: cache and invalidation

Frontend deployment is mostly about making fresh and stale behavior explicit.

Sprint index

The rule

Immutable assets can cache long; HTML/data that changes needs clear lifetimes and invalidation paths.

Example

Hashed JS assets can be cached for a long time; a personalized report route should not use broad public caching.

Practice

Choose cache headers for HTML, hashed assets, API data, and images for one product route.
