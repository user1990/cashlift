C08

Testing strategies: confidence by layer

The best test is the cheapest test that gives the needed confidence.

Sprint index

The rule

Use unit tests for pure rules, integration tests for user-visible behavior, visual tests for presentation regressions, and e2e for critical flows.

Example

Checkout pricing logic is unit-level; promo code behavior is integration-level; purchase confirmation is e2e-level.

Practice

For one flow, list three tests you would write and one test you would deliberately not write.

Write a concrete answer, then check.

Good answer direction

Strong answer: I design tests by responsibility and failure cost, not by trying to push every scenario through e2e.
