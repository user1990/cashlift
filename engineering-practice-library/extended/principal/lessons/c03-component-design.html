C03

Component design: composition before configuration

Good components make the common path simple and the unusual path possible without prop explosions.

Sprint index

The rule

Prefer composition when a component needs layout flexibility; prefer props when the variation is small and explicit.

Example

A ReportSection can own heading, loading, empty, and error structure while accepting children for domain-specific content.

Practice

Take one large component and split it into shell, domain mapper, presentational section, and primitive controls.

Write a concrete answer, then check.

Good answer direction

Strong answer: I keep domain decisions out of primitives and keep primitives boring, accessible, and reusable.
