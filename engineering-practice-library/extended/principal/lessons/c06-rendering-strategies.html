C06

Rendering strategies: CSR, SSR, SSG, ISR

Rendering strategy is a product and route decision, not a framework identity.

Sprint index

The rule

Choose by SEO, personalization, freshness, cacheability, and interaction weight.

Example

Marketing pages can be static; authenticated dashboards often need server rendering plus client islands.

Practice

Create a table for five routes: SEO, auth, freshness, interactivity, recommended rendering strategy.

Write a concrete answer, then check.

Good answer direction

Strong answer: I choose rendering per route and per interaction, then document the cache and invalidation behavior.
