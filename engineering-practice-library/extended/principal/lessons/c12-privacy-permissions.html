Privacy and permissions: browser trust boundaries

Privacy work is about minimizing data, respecting user intent, and understanding browser boundaries.

Sprint index

The rule

Use cookies, storage, and permissions only when the product need is clear and the lifetime is justified.

Example

Analytics events should avoid PII and should not store sensitive report identifiers in broadly accessible client storage.

Practice

Audit one flow for cookies, localStorage, sessionStorage, permissions, and analytics payloads.

Write a concrete answer, then check.

Good answer direction

Strong answer: I treat browser storage as a product and security decision, not a convenient dumping ground.
