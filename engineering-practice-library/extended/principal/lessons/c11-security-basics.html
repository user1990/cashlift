Security basics: XSS, CSRF, CSP

Frontend security starts with treating all input and all rendered content as hostile until proven safe.

Sprint index

The rule

Avoid unsafe HTML injection, protect state-changing requests, use secure headers, and make CSP part of defense in depth.

Example

Rendering user-provided vehicle notes with innerHTML is a risk unless sanitized and constrained by policy.

Practice

Find one place user input becomes UI. Write the validation, encoding, sanitization, and CSP assumptions.
