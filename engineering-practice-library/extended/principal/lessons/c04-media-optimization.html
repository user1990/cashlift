Media optimization: load the right asset

Media performance is mostly choosing the right bytes, dimensions, priority, and loading behavior.

Sprint index

The rule

Serve responsive sizes, modern formats, explicit dimensions, and only prioritize media that affects the first meaningful view.

Example

A hero image may need priority loading; report detail thumbnails should usually lazy-load with known width and height.

Practice

Audit one image-heavy page. For three images, write format, displayed size, intrinsic size, loading priority, and CLS risk.

Write a concrete answer, then check.

Good answer direction

Strong answer: I optimize media by matching the asset to the viewport and user journey, not by compressing everything blindly.
