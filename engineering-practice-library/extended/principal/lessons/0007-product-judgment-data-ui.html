Lesson 0007

Product judgment: data confidence UI

In data-heavy products, frontend should communicate certainty, uncertainty, and consequence.

Sprint index

The product move

When data is uncertain, do not pretend it is precise. Help the user understand risk, confidence level, evidence, and the next action.

Primary sources: PostHog Docs, PostHog Feature Flags, Sanity Docs.

Example

Bad UI: "Mileage: 132,000 km" when two sources conflict. Better UI: "Mileage inconsistency detected", a timeline with sources, confidence indicator, and questions the buyer can ask the seller.

Practice

Write a mini spec for one uncertain data case: problem, non-goal, user decision, event, guardrail.

Write first, then check.

Good answer direction

"Data-heavy UI should not hide uncertainty. I would show the confidence level, source trail, consequence, and next action. Then I would roll it out behind a flag and measure whether users understand the risk better."
