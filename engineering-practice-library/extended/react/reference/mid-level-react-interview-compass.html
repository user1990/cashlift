Reference card

Mid-level React interview compass

Answer shape

  1. Clarify the user and system constraints.
  2. Name the simplest viable design.
  3. Explain the trade-off and failure mode.
  4. Say how you would verify it.

Performance order

  1. Reproduce and measure the slow interaction.
  2. Use React/browser profiling to locate the expensive work.
  3. Reduce the work: state placement, rendering, network, or paint.
  4. Measure again; add memoization only when it protects a measured bottleneck.

One-line distinctions

Render is React calling components; commit applies necessary DOM changes; paint is the browser drawing pixels.

State is data that changes over time and drives UI; derived data is calculated during render; an Effect synchronizes with an external system.

useMemo caches a calculation; memo can skip child rendering when props are unchanged; neither proves a performance issue exists.

Context is dependency injection and subscription—not a universal global store. Provider value changes re-render consumers.
