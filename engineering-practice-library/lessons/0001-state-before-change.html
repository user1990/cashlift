Prompting field guide · lesson 01

State before change.

The first reliable prompt does not ask for code. It asks the agent to prove which reality it is about to mutate.

The one-sentence rule

No mutation before the agent proves which state it is mutating.

That means checkout, branch, commit, dirty files, runtime, dependency state, route or command, and baseline behavior. A correct fix in the wrong checkout is still a failure.

Retrieve before reading on

Which prompt opening creates the strongest safety gate?

Bad → better

Bad:

Give live preview on latest master.

Why it fails: “latest” and “live” are ambiguous. The agent can use a stale branch, a dirty checkout, or a server from another directory.

Better:

Before editing, report:

1. Current directory, branch, commit, and dirty files.
2. Whether this is the intended checkout.
3. Runtime and package-manager versions.
4. The exact route or command used for the baseline.
5. Any existing implementation of the behavior.

Do not edit until the baseline is confirmed. If the checkout is stale, dirty in a conflicting way, or different from the requested branch, stop and explain the mismatch.

Copy/paste gate

STATE GATE

Before making any change:

- inspect the current checkout and branch
- inspect dirty/untracked files
- inspect the current commit
- verify runtime and dependency state
- reproduce the current behavior
- identify the exact files and route involved

Return a short baseline report first. Do not edit until the state is confirmed.

Apply it to the Spotify-like practice domain

Before asking an agent to “make the sidebar feel like Spotify,” make it identify the target checkout, route, viewport, existing layout, and current screenshot. Then define the visual baseline: #121212 base, #181818 surface, #1ed760 functional accent, dense 8px spacing, and the current sidebar/mobile behavior.

That turns taste into an observable starting state. Read the complete [agent prompting playbook](../reference/01-agent-prompting-playbook.html) and [Spotify-like design system](../reference/02-spotify-design-system.html) before the next lesson.

Two-minute practice

Rewrite one real request you might send to an agent. Include the state gate, the intended route or surface, and the baseline evidence you expect back.
