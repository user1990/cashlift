Lesson 01 · Foundation

Fundamentals are a feedback system

AI changes who types the code. It does not change the need to detect when the code is wrong, tangled, or unsafe.

Knowledge → judgmentOne retrieval checkNo setup required

Win for this lesson

Given a development rule, you can place it in the right enforcement layer: prompt, executable check, or human decision.

An agent can produce a plausible implementation in minutes. That speed compresses the interval between decisions: good design compounds faster, but so does accidental complexity. The useful question is not “Can the agent write this?” It is “What feedback will reveal that the result is wrong?”

Three enforcement layers

P

Prompt: direction

Use prose for goals, local context, and preferences. It is flexible and cheap, but interpretation is probabilistic. A prompt can request “keep modules independent”; it cannot prove that they are.

✓

Check: invariant

Use tests, types, linters, dependency rules, and security policies for conditions with a machine-detectable pass or fail. The same input receives the same verdict.

H

Human: strategy

Keep product intent, tradeoffs, architecture choices, risk acceptance, and taste with a responsible person. These require context and judgment, not merely consistency.

StatementBest homeWhy
“Prefer clear names.”Prompt + reviewMeaning and taste are contextual.
“Domain must not import UI.”Dependency checkThe import graph is mechanically inspectable.
“Refunds require manager approval.”Behavior test + human policyThe rule is testable; the policy choice is strategic.
“Never expose a secret.”Multiple controlsHigh impact requires prevention, scanning, permissions, and review.

Do not overread “lost in the middle”

The cited research found positional degradation on specific long-context retrieval and question-answering tasks. It supports keeping context relevant and checks external. It does not prove that every long prompt is ignored or that repository instructions are useless.

The smallest useful agent loop

01IntentDefine one observable outcome.
02ImplementLet the agent inspect and change.
03VerifyRun deterministic checks.
04JudgeHuman reviews outcome and risk.

The loop matters more than the number of agents. One agent with a clear target and fast checks is a better starting point than a five-role pipeline with vague acceptance criteria.

An API must always emit a required version header. Where is the strongest primary enforcement?

Primary research

Lost in the Middle: How Language Models Use Long Contexts

Read the abstract, Figure 1, and limitations. Notice that the evidence is about position-sensitive use of context, not a universal law that agents ignore long instructions.
