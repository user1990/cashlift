Lesson 05 · Test strength

Mutation testing tests the tests

Coverage asks whether code ran. Mutation asks whether a small, deliberate mistake would be noticed.

MutantsTest oraclesSurvivor triage

Win for this lesson

You can interpret a surviving mutant, write a test that distinguishes the changed behavior, or classify the mutant with an explicit reason.

The mutation loop

01ChangeTool inserts one small fault.
02RunRelevant tests execute.
03ObserveFailure kills; success survives.
04TriageTest, refactor, classify, or ignore.

Production rule

function canEnter(age: number) {
  return age >= 18;
}

Existing test

expect(canEnter(21)).toBe(true);

A mutator changes >= to >. The test still passes, so the mutant survives. The suite has not specified what happens at exactly 18.

Behavioral distinction

expect(canEnter(18)).toBe(true); // kills the boundary mutant
expect(canEnter(17)).toBe(false);

A survivor is a question, not a command

CauseResponse
Missing boundary or outcome assertionAdd the smallest test that names the distinction.
Dead or unreachable codeDelete or simplify the production code.
Equivalent behaviorClassify it; no possible test can distinguish it.
Low-value logging or defensive pathDocument a scoped exception with owner and review point.
Brittle implementation-coupled test neededReconsider the interface before adding the test.

“Kill every mutant” is unsafe as an absolute

Equivalent and redundant mutants exist. A 100% mutation score can reward noisy or implementation-coupled tests. The stronger policy is: every relevant survivor is killed or classified with a reason, and the baseline never silently regresses.

Put mutation in the right loop

  • While coding: mutate one changed file or package.
  • On pull request: mutate changed code; fail only on meaningful regression.
  • Scheduled: run the broader suite when cost is too high for every change.
  • Human checkpoint: review survivors that imply a missing requirement or questionable oracle.

An agent is excellent at the repetitive loop of locating a survivor and proposing a focused test. A human should still reject tests that merely mirror the implementation.

Retrieval check

The >= to > mutant survives for an age rule. What response adds the most evidence?

Survivor triage

Pick one conditional from a real project. Imagine the operator flipped. What test would fail? If none, is the test missing, the code unnecessary, or the mutant equivalent?
