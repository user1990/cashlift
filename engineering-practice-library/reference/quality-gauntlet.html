Quick reference

The AI quality gauntlet

A compact story-to-acceptance loop. Roles are responsibilities; they do not require separate agents.

StageInput → outputDetectsHuman checkpoint
1 · SpecifyStory → rules, examples, open questions, QAAmbiguity, missing edge cases, wrong oracleApprove value, policy, risk
2 · ImplementExamples → code, types, focused testsCompile errors, behavioral mismatchConfirm scope remains narrow
3 · CleanWorking diff → legible modulesMixed responsibilities, complexity, driftChoose boundaries and domain names
4 · HardenPassing suite → stronger evidenceWeak assertions, forbidden dependencies, risk gapsClassify survivors and exceptions
5 · AcceptCandidate → observed user outcomeAssembly, integration, UX, missing requirementAccept or reject final behavior

Evidence ladder

FASTBuild + typesCan the program be formed?
LOCALFocused testsDoes the unit distinguish behaviors?
STATICLint + architectureDoes structure respect invariants?
STRONGMutationWould the suite notice faults?
WHOLEQA + humanDoes the system solve the intended problem?

Diagnostic routing

SymptomFirst questionLikely next move
Agent loops between fixesIs the task or module mixing unrelated decisions?Shrink the slice; expose a stable boundary.
All tests pass; feature is wrongDid acceptance criteria name an observable oracle?Fix the example and QA before more unit tests.
Coverage is lowWhat risky behavior was never executed?Add one meaningful assertion or remove dead code.
Coverage is high; mutant survivesWhich behavioral distinction is absent?Add a boundary test or classify the mutant.
Changes spread across foldersWhich decision lacks an owner?Regroup by capability; narrow the interface.
Architecture keeps driftingCan the forbidden edge be observed mechanically?Encode one dependency fitness function.
Checks dominate elapsed timeDoes each stage detect distinct valuable defects?Target changed code; schedule expensive checks.

Definition of done for one AI-assisted slice

Do not cargo-cult the full pipeline

Begin with existing checks plus one missing high-value signal. Add a role or gate only when it improves accepted lead time, human attention, rework, or escaped defects.
