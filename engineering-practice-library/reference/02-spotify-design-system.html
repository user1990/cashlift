Complete supplied design reference

Spotify-like UI system

A dark, immersive, content-first app language: the interface recedes into charcoal so album art, media, and meaningful state become the primary source of color.

1. Visual theme and atmosphere

Use a near-black immersive dark theme: #121212, #181818, and #1f1f1f. Album art and content provide the primary color. Spotify Green #1ed760 is a singular functional accent, never decoration. The UI should feel like a theater-like premium audio device: tactile, rounded, dense, and built for touch.

Typography uses SpotifyMixUI and SpotifyMixUITitle, with CircularSp-inspired fallbacks and global script coverage: Arabic, Hebrew, Cyrillic, Greek, Devanagari, and CJK. Use weight 700 for emphasis/navigation, 600 sparingly, and 400 for body. Buttons use uppercase labels with positive letter-spacing, generally 1.4px–2px.

  • Near-black immersive dark theme; UI disappears behind content.
  • Spotify Green as singular brand accent; functional only.
  • SpotifyMixUI/CircularSp-style fonts with global script support.
  • Pill buttons and circular controls; rounded and touch-optimized.
  • Uppercase button labels with wide tracking.
  • Heavy shadows on elevated elements.
  • Album art as primary color source; UI achromatic by design.

4. Component styling

Buttons

  • Dark pill: #1f1f1f background, white or silver text, 8px 16px padding, 9999px radius; navigation and secondary actions.
  • Dark large pill: #181818, white text, 0px 43px padding, 500px radius; primary app navigation.
  • Light pill: #eeeeee, #181818 text, 500px radius; rare light-mode CTAs.
  • Outlined pill: transparent, white text, 1px solid #7c7c7c, 4px 16px 4px 36px padding, 9999px radius; follow and secondary actions.
  • Circular play: #1f1f1f, white, 12px padding, 50% radius; play/pause.

Cards and containers

Use #181818 or #1f1f1f, 6px–8px radius, usually no visible borders, slight background lightening on hover, and medium shadow rgba(0,0,0,0.3) 0px 8px 8px on elevated cards.

Inputs

Search uses #1f1f1f, white text, 500px radius, 12px 96px 12px 48px padding, and focus border #000000 with 1px solid outline. Use the inset border-shadow combo where a recessed tactile quality is needed.

Navigation

Sidebar uses #121212. Active items: 14px, 700, white. Inactive: 14px, 400, #b3b3b3. Use circular icon buttons and a green logo top-left.

5. Layout principles

Spacing: base unit 8px; practical scale 1px, 2px, 3px, 4px, 5px, 6px, 8px, 10px, 12px, 14px, 15px, 16px, 20px.

Grid: fixed sidebar plus main content; grid-based album/playlist cards; full-width now-playing bar at the bottom; responsive content fills the remaining area.

Whitespace: dark compression and content density over breathing room. This is an app, not a marketing site; every pixel serves the listening experience. Dark surfaces provide visual rest without large gaps.

Radius scale: 2px badges/explicit tags; 4px inputs/small elements; 6px album art/cards; 8px sections/dialogs; 10px–20px panels/overlays; 100px large pills; 500px primary buttons/search; 9999px navigation pills/search; 50% play buttons, avatars, icons.

Shadow philosophy: the 0.5 opacity, 24px blur shadow makes dialogs float in darkness; the 0.3 opacity, 8px blur shadow gives cards subtle lift; inset shadows create recessed tactility.

7. Do and don’t

Do

  • Use near-black backgrounds and depth through shade variation.
  • Apply green only to play controls, active states, and primary CTAs.
  • Use pills for buttons and circles for play controls.
  • Use uppercase plus 1.4px–2px tracking on buttons.
  • Keep typography compact, 10px–24px.
  • Use heavy 0.3–0.5 opacity shadows.
  • Let album art provide the color; keep the UI achromatic.

Don’t

  • Do not use Spotify Green decoratively or on backgrounds.
  • Do not use light backgrounds for primary surfaces.
  • Do not skip pill/circle geometry.
  • Do not use thin or subtle shadows on dark backgrounds.
  • Do not add additional brand colors.
  • Do not use relaxed line-heights.
  • Do not expose raw gray borders; prefer shadow-based or inset borders.

9. Agent prompt guide

Quick color: background #121212; surface #181818; text #ffffff; secondary #b3b3b3; accent #1ed760; border #4d4d4d; error #f3727f.

Copy/paste component prompts

Create a dark card: #181818 background, 8px radius. Title at 16px SpotifyMixUI weight 700, white text. Subtitle at 14px weight 400, #b3b3b3. Shadow rgba(0,0,0,0.3) 0px 8px 8px on hover.

Design a pill button: #1f1f1f background, white text, 9999px radius, 8px 16px padding. 14px SpotifyMixUI weight 700, uppercase, letter-spacing 1.4px.

Build a circular play button: Spotify Green (#1ed760) background, #000000 icon, 50% radius, 12px padding.

Create search input: #1f1f1f background, white text, 500px radius, 12px 48px padding. Inset border: rgb(124,124,124) 0px 0px 0px 1px inset.

Design navigation sidebar: #121212 background. Active items: 14px weight 700, white. Inactive: 14px weight 400, #b3b3b3.

Iteration guide

  1. Start with #121212; everything lives in near-black darkness.
  2. Use Spotify Green for functional highlights only: play, active, CTA.
  3. Pill everything: 500px for large, 9999px for small, 50% for circular.
  4. Use uppercase plus wide tracking on buttons.
  5. Use heavy 0.3–0.5 opacity shadows; light shadows disappear on dark.
  6. Let album art provide all color; keep the UI achromatic.
